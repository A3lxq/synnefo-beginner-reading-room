# Case File 2: Reading Room

Case File 1 pointed toward a second system: Halcyon's internal "Reading
Room" — a staff library portal used, according to Priya Okonkwo-Reyes'
notes, to quietly stage documents that should never have left their
original department.

The catalog, the staff login, and the "suggest a cover" upload feature are
all still live. Nobody closed this one down either.

Priya's note on this file is shorter than Case File 1's: "Whoever built
this trusted the browser more than the server. Start there."
